Contract

What this layer promises downstream

The data layer has one job: hand every consumer the same rows, in the same form, reproducibly — and surface anything about the corpus that would silently invalidate a result further down.

  • Deterministic. Every split is an index array generated from a fixed seed. Re-running the audit reproduces them byte for byte.
  • Non-destructive. The corpus is read-only. Nothing is filtered, cleaned, or rewritten on disk.
  • Self-describing. Two parameters — max_length and normalize_version — are emitted into the config, so consumers never guess them.
  • Honest about defects. Duplicates and label conflicts are counted and reported, not quietly dropped.

Invariants

Three rules that hold at this layer

Rule

Seeds are fixed and shared

The 40k subsample and the calib/holdout permutation both use seed 42. Every training run must load the identical subset, or the three-seed model comparison is not a controlled experiment.

Rule

Calibration and rates never share rows

Validation splits 50/50. Fitting thresholds and measuring error rates on the same rows would produce a bootstrap interval that is too narrow — confident and wrong.

Rule

Test is absent, not merely unused

Every notebook but the last calls ds.pop("test"), so the split does not exist in its namespace. Compliance is checked by grep, not by memory.

Gap

The dataset this layer does not have

Not yet built

300 hand-labelled French product-and-service comments, 3-class. Everything above describes film reviews. The product question this system exists to answer concerns a different domain, and nothing here measures that gap.

Two things wait on it: the neutral-band thresholds are currently set by a target abstention rate rather than fitted to real 3-class labels, and the confidence interval propagates only holdout uncertainty — it accounts for zero domain shift, so off-domain it reports tight bounds it has not earned.

It cannot be auto-generated. Labelling it with a model would make the inter-annotator figure measure agreement with the system under test.
